### Pro Tips for Learning

**How to Approach Problems:**
- Read the problem statement carefully
- Break it down into smaller components
- Write pseudocode before actual code
- Test with simple cases first
- Handle edge cases systematically

**When You're Stuck:**
- Read error messages carefully . try to figure out what is exactly wrong 
- Print intermediate values to debug

**Best Practices:**
- Write comments explaining your logic
- Keep your code clean and organized
- Learn to use Git for version control early
